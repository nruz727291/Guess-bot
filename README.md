# 🎮 Guess The Number - Telegram Multiplayer Bot

A production-grade Telegram multiplayer bot built with Pyrogram + MongoDB.

## Features
- Multiplayer rooms (2-5 players)
- Turn-based guessing with hints
- Quick match matchmaking
- Coin economy with daily rewards
- Leaderboards with pagination
- Anti-spam protection
- Auto cleanup background tasks
- Crash recovery via persistent state

## Tech Stack
- **Python 3.11**
- **Pyrogram 2.x** (Telegram)
- **Motor** (async MongoDB)
- **MongoDB Atlas** (database)
- **Railway** (deployment)
